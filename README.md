# Got It All

Приложение помогает планировать разовые и регулярные покупки с помощью упорядоченных списков.

## Возможности

- создание и редактирование списков покупок;
- отметка купленных товаров, ручная и алфавитная сортировка;
- настройка количества и единиц измерения;
- закрепление часто используемых списков;
- архивирование, восстановление и очистка завершённых списков;
- локальные напоминания через `UserNotifications` без доступа к календарю;
- русская и английская локализация;
- светлая, тёмная и автоматическая тема с переключением по времени суток.

## Техническая информация

- Swift и UIKit;
- интерфейс создан программно;
- MVVM с координатором и внедрением сервисов;
- Core Data с автоматической лёгкой миграцией;
- iPhone, портретная ориентация;
- минимальная версия iOS: 16.6.

## Тестирование

В проект добавлен target `ShoppingListTests`. Тесты проверяют порядок хранения товаров, восстановление списков,
сохранение единственного и последнего элемента, отсутствие дублирования при повторной загрузке, блокировку выбора всех товаров
во время редактирования, автоматическую тему и единообразное название приложения.

Для запуска откройте `ShoppingList.xcodeproj` в Xcode и выполните **Product → Test**.
